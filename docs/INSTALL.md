# Install

1. Put `harness-bootstrap.sh`, your `.env`, and (optional) `.harness-allowlist` in one folder.
2. `cd` to where you want `harness/` created.
3. Run `bash /path/to/that/folder/harness-bootstrap.sh`.
4. `cd` into a project and run `harness`.

Windows: use Git Bash, inside your user folder.
